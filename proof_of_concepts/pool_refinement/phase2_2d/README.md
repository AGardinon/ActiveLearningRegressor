# Phase 2: adaptive refinement from a 5-point pool (2D Styblinski-Tang)

With an extremely sparse starting pool, refinement is the only source of new candidates. Where
can it take the campaign, and does the best-first centroid rule get trapped in a decoy basin?

- **Function:** Styblinski-Tang 2D on [-4, 4]², negated. The global optimum is at
  (-2.90, -2.90) with y = 78.33; the decoy corners have 64.20 (twice) and 50.06.
- **Campaign:**
  - the pool is 5 LHS points set by the seed, and the campaign starts from 3 random points of it;
  - each cycle acquires 1 point by exploration (mutual info) and 1 by expected improvement;
  - 20 cycles; refinement every 5 acquisitions, with 2 cubes × 25 points; fps batch selection;
  - GPR as in Phase 1 (`MATERN_W`, 50 restarts).
- **No run without refinement:** the pool runs out after cycle 1.

| Variant | `adaptive_refinement` |
|---|---|
| `maximin` | `refinement_centroid_selection: maximin`, `half_side_length_strategy: density` |
| `bestfirst` | `best_first` (top fraction 0.2), `density` |
| `maximin_fixed` | `maximin`, `fixed` with `base_fraction: 0.5` (constant cube size) |
| `bestfirst_fixed` | `best_first`, `fixed` with `base_fraction: 0.5` |

```bash
# ./run.sh <variant> [reps=5] [seed=13]
PY=/path/to/env/bin/python ./run.sh bestfirst 5 21   # -> runs/s21/bestfirst/, runs/s21/bestfirst.log
```

All 4 variants × 5 seeds × 5 reps run in about a minute (10 jobs in parallel).

## Results (seeds 7, 13, 21, 42, 101; 5 reps each)

Repetitions reaching the global basin (best y > 70):

| Seeds | `maximin` | `bestfirst` | `maximin_fixed` | `bestfirst_fixed` |
|---|---|---|---|---|
| 7, 13: a pool point within 1.23 of the optimum | 7/10 | **10/10** | 9/10 | **10/10** |
| 21, 42, 101: nearest pool point 2.35–2.90 away | 0/15 | 0/15 | 2/15 | 0/15 |

- **Refinement is a local search around the starting pool.**
  - The first cube has a half-side of about 1.0–1.35 (0.5 scaled units).
  - With `density`, the half-side then drops to about 0.2, then 0.06, then 0.01: the rule sees
    the 25 points it just added.
  - The campaign reaches the global basin only when a pool point lies within reach of the
    first cubes.
- **Best first is better when the global basin is reachable** (10/10 against 7/10, and it gets
  there faster).
- **Best first stays in the incumbent's basin when it is not.**
  - Even with constant-size cubes it never left a decoy basin (0/15).
  - `maximin_fixed` escaped twice (2/15): constant cubes let the maximin centres travel.
- **The limit is shared by every variant:** no rule reaches a basin the pool does not touch. Global
  coverage has to come from the starting pool (or from a global component in refinement).
